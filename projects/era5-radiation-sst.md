# 全球大气顶短波辐射与海温时空耦合分析
> 气象时空数据分析 · Python 科研可视化 · 课程论文

## 项目简介
基于 CERES 卫星观测辐射数据与 ERA5 再分析海温数据，针对 2010-2020 年全球尺度，开展大气顶短波辐射通量（TOA SW）与海表温度（SST）的时空特征及耦合机制研究。
使用 Python 完成多源数据网格对齐、时间序列分析、空间相关计算与全维度可视化，揭示两者「热带正相关、中纬负相关」的空间分异规律及物理反馈机制。

本项目为复旦大学《大数据分析与可视化》课程期末论文，获评优秀。

## 核心成果
1.  完成两套不同分辨率数据的双线性插值对齐，构建 1°×1° 全球逐月分析数据集，覆盖 11 年时间序列
2.  实现全球逐网格趋势计算、显著性检验与 Pearson 空间相关分析，量化两者耦合的空间分异特征
3.  输出系列高质量可视化图表，包含全球空间分布、季节循环、时间序列、相关系数分布等，支撑完整科研结论

## 技术方案
### 数据层：多源数据融合
| 数据类型 | 数据集 | 原始分辨率 | 处理后分辨率 | 时间范围 |
|---|---|---|---|---|
| 大气顶短波辐射 | CERES EBAF-TOA v4.2 | 1°×1° | 1°×1° | 2010-2020 月均 |
| 海表温度 | ERA5 再分析 | 0.25°×0.25° | 1°×1° | 2010-2020 月均 |
| 总云量 | ISCCP D2 | 2.5°×2.5° | 1°×1° | 2010-2020 月均 |

- 统一网格：通过双线性插值将不同分辨率数据统一至 1°×1° 标准网格
- 质量控制：剔除低可信度像元，处理缺测值，转换为 NetCDF 格式批量处理
- 距平计算：提取季节异常值，剥离气候平均态，聚焦年际与耦合信号

### 分析层：时空统计方法
- **时间序列分析**：逐网格线性回归计算变化趋势，F 检验显著性（p<0.05）
- **空间相关分析**：逐网格 Pearson 相关系数计算，t 检验显著性，量化 TOA SW 与 SST 的空间耦合
- **季节合成分析**：按四季合成平均，分离季节循环与年际异常信号

### 工具栈
- **数据处理**：Python + xarray + pandas
- **可视化**：Matplotlib + Cartopy 地图投影
- **统计检验**：SciPy 显著性检验模块

## 分析结果展示
### 1. TOA SW 全球空间分布与季节循环
大气顶短波辐射通量整体呈现「副热带高、高纬低，干旱区高、多雨区低」的空间格局，高值区随太阳直射点南北移动，呈现完整的季节循环。

### 2. SST 时空特征
海表温度呈现「赤道高、两极低」的纬度梯度，热带西太平洋暖池区为全球高值中心；时间序列上 11 年整体呈微弱增温趋势，ENSO 关键区波动幅度为全球平均的 6 倍。

![SST多年平均全球分布](/images/sst_climatology.png)
*图：2010-2020年海表温度多年平均全球分布*

### 3. 两者空间耦合特征
TOA SW 与 SST 的相关性呈现显著的空间分异：热带海域显著正相关，中纬度海域弱负相关，高纬度无显著相关，分别对应不同的海-气-辐射反馈机制。

![TOA SW与SST相关系数分布](/images/radiation_sst_correlation.png)
*图：TOA SW 与 SST 的 Pearson 相关系数全球分布，斜线区域为 p<0.05 显著区*

#### 耦合机制
- **热带正相关（r=0.4~0.6）**：SST 升高 → 海表蒸发增强 → 对流云分散、云顶降低 → 短波辐射反射减少 → TOA SW 升高，符合 Bjerknes 反馈机制
- **中纬负相关（r=-0.2~-0.4）**：SST 升高 → 热力梯度增强 → 锋面气旋活动增多 → 层状云覆盖扩大 → 短波反射增加 → TOA SW 降低
- **高纬无显著相关**：海冰覆盖导致数据缺失，且辐射信号本身微弱，未通过显著性检验

## 核心结论
1.  **空间格局**：TOA SW 全球分布受太阳高度角、云量、下垫面类型共同控制，副热带干旱区最高（250-280 W·m⁻²），热带多雨区与高纬地区最低（100-160 W·m⁻²）
2.  **季节循环**：TOA SW 高值区随太阳直射点南北移动，北半球夏季北移、南半球夏季南移，春秋季呈赤道对称分布
3.  **耦合模式**：两者相关性呈现「热带正、中纬负」的空间分异，分别对应对流云反馈与锋面云调控两种物理机制
4.  **年际信号**：ENSO 关键区 SST 异常通过云量调控辐射通量，是热带海-气-辐射耦合的核心驱动因子
