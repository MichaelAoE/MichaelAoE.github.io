# 豆瓣影视数据分析与 BI 可视化
> MySQL · SQL 数据建模 · Metabase BI 可视化 · 用户画像分析

## 项目简介
基于豆瓣影视公开数据集，围绕影片基础信息、用户评分、评论内容三大维度，完成从原始数据清洗、MySQL 多表建模、指标计算到 BI 可视化看板搭建的全链路数据分析。
通过结构化 SQL 逻辑完成核心业务指标统计，搭建交互式可视化看板，挖掘影视内容分布规律、用户评分偏好、口碑影响因素等业务洞察。

## 核心成果
1.  完成十万级影视数据的 MySQL 入库与标准化清洗，覆盖影片、评分、评论三张核心表，统一数据口径
2.  基于 Metabase 搭建多维度交互式 BI 看板，支持内容分类、时间趋势、评分分布等维度下钻筛选
3.  输出 5+ 条可落地的业务洞察结论，沉淀「数据入库-SQL 计算-可视化输出」的标准化分析流程

## 技术方案
### 数据层：MySQL 数据处理与建模
- **表结构设计**：设计影片信息表、评分表、用户评论表三范式表结构，建立主键与关联索引，优化查询效率
- **数据清洗**：通过 SQL 完成全量数据去重、缺失值填充、异常值筛选、字段格式统一
- **指标计算**：通过多表联查、分组聚合、窗口函数，计算各维度核心统计指标

### 分析层：多维度业务分析
- **内容维度**：影片类型、地区、年份的数量分布与评分分布对比
- **用户维度**：评分偏好分层、评论活跃度、高分/低分影片的用户特征
- **关联分析**：评分与评论量、影片时长、主创团队的相关性分析
- **趋势分析**：近十年影视数量、评分中位数的年度变化趋势

### 工程层：自动化脚本
配套 Python 自动化脚本，实现环境配置、数据入库、看板配置、报表生成全流程一键执行，支持快速复现整套分析环境。

## BI 可视化看板
基于 Metabase 搭建交互式分析看板，分为四大核心模块，支持筛选、下钻、联动操作。

### 看板总览
![豆瓣影视数据分析BI看板](/images/douban_bi_dashboard.png)
*图：多维度交互式分析看板总览*

### 1. 总览概览模块
- **核心指标卡**：影片总数、平均评分、评论总条数、高分片占比
- **分布图表**：类型占比饼图、地区分布柱状图、评分分布直方图
- **趋势图表**：近十年影片数量与评分中位数双轴折线图

### 2. 内容分析模块
- 按类型、地区、年份多维度交叉统计影片数量与平均评分
- Top 20 高分/低分影片榜单，支持按类型筛选
- 评分分段分布对比，分析不同质量区间的影片特征

### 3. 用户行为模块
- 评分人数与评分分值的散点关联分析
- 评论活跃度分布，识别高互动影片特征
- 高分/低分评论关键词词频对比

### 4. 专项分析模块
- 国产影片近五年口碑趋势追踪
- 不同类型影片的评分方差对比（口碑稳定性分析）
- 时长与评分的相关性分析

## 核心业务洞察
- 剧情、纪录片类影片整体评分中位数显著高于商业类型片，口碑与票房导向呈现明显分化
- 评分人数与评分分值呈现弱正相关，高讨论度影片的质量整体更稳定，极端低分占比更低
- 近五年国产影片数量占比持续上升，评分中位数稳步提升，口碑表现逐年改善
- 评论负面评价集中在剧情逻辑、演员表演两个核心维度，是影响口碑的主要因素

## 项目亮点
1.  **完整数据链路**：覆盖原始数据导入、SQL 清洗建模、指标计算到 BI 可视化输出全流程，链路完整可复现
2.  **业务导向分析**：不局限于数据统计，输出可解释的业务洞察，而非纯技术指标堆砌
3.  **工程化复用**：表结构设计规范，SQL 逻辑模块化，配套自动化脚本，分析流程可快速迁移到其他内容数据分析场景
