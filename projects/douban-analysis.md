# 豆瓣影视数据分析与 BI 可视化
> MySQL · SQL 数据清洗 · BI 可视化 · 用户画像分析

## 项目简介
基于豆瓣影视公开数据集，围绕影片信息、用户评分、评论数据，完成从数据清洗、指标计算到可视化看板搭建的全流程数据分析。通过 SQL 多表查询完成核心业务指标统计，搭建 BI 可视化 dashboard，挖掘影视内容分布、用户偏好、评分规律等业务洞察。

## 核心成果
1.  完成百万级数据的 MySQL 入库与清洗，统一数据口径，处理缺失值与异常值
2.  搭建多维度 BI 可视化看板，覆盖内容分类、评分分布、用户偏好等核心分析维度
3.  输出 5+ 条业务洞察结论，沉淀标准化数据分析与报表输出流程

## 技术方案
### 数据层：MySQL 数据处理
- **数据入库**：多源原始数据清洗后导入 MySQL，设计规范化表结构
- **数据清洗**：SQL 完成去重、缺失值处理、异常值筛选、维度字段统一
- **指标计算**：通过多表联查、分组聚合、窗口函数，计算各维度核心统计指标

### 分析层：核心分析维度
- 内容维度：类型、地区、年份的数量与评分分布
- 用户维度：评分偏好、评论活跃度、高分/低分影片特征
- 关联分析：评分与评论量、影片时长、主创团队的相关性

### 呈现层：BI 可视化
- 使用 BI 工具搭建交互式看板，支持维度筛选与下钻
- 核心图表：评分分布直方图、类型占比饼图、年份趋势折线图、Top 榜单表格

### 核心洞察
- 不同类型影片的评分中位数存在显著差异，剧情、纪录片类整体评分偏高
- 评分人数与评分分值呈现弱正相关，热门影片质量整体更稳定
- 近五年国产影片数量占比持续上升，评分中位数稳步提升

## 项目亮点
1.  **完整数据链路**：覆盖原始数据入库、SQL 清洗、指标计算到可视化输出全流程
2.  **业务导向分析**：不只是做数据统计，更输出可落地的业务洞察结论
3.  **工程化思维**：表结构设计规范，SQL 逻辑可复用，分析流程可迁移到其他业务场景
