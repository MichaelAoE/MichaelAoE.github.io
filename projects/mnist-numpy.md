# 纯 NumPy 实现 MLP 与 CNN 手写数字识别
> 底层神经网络实现 | 反向传播推导 | 正则化实验

## 项目简介
不依赖 PyTorch、TensorFlow 等深度学习框架，**纯 NumPy 从零实现**多层感知机（MLP）与卷积神经网络（CNN），完整手写前向传播、反向传播与参数更新全流程，深入理解神经网络底层数学原理。

## 核心实现
### 多层感知机（MLP）
- 支持自定义网络层数与神经元数量
- 实现 Sigmoid、ReLU 等激活函数及其导数
- 手写反向传播链式求导，完成梯度计算与权重更新
- 加入 Dropout 正则化、学习率指数衰减

### 卷积神经网络（CNN）
- 从零实现卷积层、池化层、全连接层
- 手写卷积运算、反向传播梯度计算
- 支持多卷积核、多通道输入输出

## 实验结果
| 模型 | 测试集准确率 |
|---|---:|
| 两层 MLP | ~97.2% |
| 简单 CNN（2卷积+1全连接） | ~98.5% |
| CNN + Dropout + 学习率衰减 | **~98.8%** |

## 项目亮点
1.  完全基于 NumPy 底层实现，不调用任何深度学习框架 API，深入理解反向传播数学原理
2.  模块化代码设计，各层解耦，可灵活组合网络结构
3.  配套多组消融实验，验证正则化、学习率调度对模型效果的影响
